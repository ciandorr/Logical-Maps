# Actuality ∧ Self-atoms are strong worlds (type t) ⇒ Strong Actuality

<p class='cert'>Result — Source: Misc.; produced by Cian Dorr, 25 October 2026; recorded by Claude Fable 5.1 (Anthropic), prompted by Cian Dorr, 25 October 2026.</p>

## Premises

- **Actuality.** There is a true proposition that entails every true proposition.
- **Self-atoms are strong worlds (type t).** Every self-atom is a strong world proposition.

## Conclusion

- **Strong Actuality.** There is a true strong world proposition: a true proposition that necessarily entails every proposition or its negation.

## Proof

The true atom that Actuality supplies is a self-atom, since it entails every truth, including the truth that it entails every truth; Self-atoms are strong worlds (type t) makes it a strong world, so it is a true strong world.
