# Actuality ⇒ Actual Profile

<p class='cert'>Result — Source: Classicism (2023 draft); produced by Andrew Bacon and Cian Dorr; recorded by OpenAI Codex (GPT-6), 17 September 2026.</p>

## Premises

- **Actuality.** There is a true proposition that entails every true proposition.

## Conclusion

- **Actual Profile.** Every finite tuple has a true relational profile entailing every relation it instantiates; the tuple may be empty.

## Proof

Let w witness Actuality. At a tuple $\bar x$, use the relation $\lambda\bar y\, .\,w\land\bigwedge_i x_i=y_i$. It holds at $\bar x$. If $Z[\bar x]$ is true, w entails that truth; NI preserves the tuple identities, so the proposed relation entails Z. This gives the required profile for every type tuple.
