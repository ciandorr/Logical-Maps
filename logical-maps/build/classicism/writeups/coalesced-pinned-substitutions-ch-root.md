## Package

- **□Atomlessness.** Necessarily, every possible proposition has a possible proposition strictly below it.
- **□5-necessities are two-hat necessary.** Necessarily, whatever is 5-necessary is two-hat necessary. In C this is the identity $\Box_5=\hat{\hat\Box}$.
- **□Intensional Choice.** Necessarily, if a property is necessarily instantiated, then some property entailing it is necessarily uniquely instantiated.
- **Modal Well-Ordering.** Every type, including e, has a relation that is necessarily a well-order of it.
- **Necessity of Arithmetic.** Every arithmetical sentence is either necessarily true or necessarily false, given that possibly zero is not a successor and successor is injective on numbers, where the numbers are the finite cardinalities of properties of a type $\sigma$. One sentence for each type $\sigma$ and each arithmetical sentence at $\sigma$.
- **Arithmetic Necessitism.** Given that necessarily zero is not a successor and successor is injective on numbers, the numbers at $\sigma$ form a rigid property with necessarily distinct instances. One sentence for each type $\sigma$.
- **BF.** The Barcan Formula at every type. The predicate formulation closes the formula schema using lambda abstraction.
- **Two-hat necessities are ND-necessary.** Whatever is two-hat necessary is ND-necessary: the distinctness-preserving modality agrees with its hat.
- **5-necessities are two-hat necessary.** Whatever is 5-necessary is two-hat necessary.
- **Transversal Choice.** Every equivalence relation, at any type including e, has a transversal, that is, a property with exactly one instance in each of its cells.
- **Axiom of Infinity (type e).** There are not finitely many individuals. No finite cardinality holds of the universal property, so the domain of the type cannot be exhausted by finitely many steps from the empty property.
- **Independence (signature Σ).** No constant of Sigma is a pure operation applied to other constants: for a closed pure term A and distinct constants c, d_1,…,d_n with n ≥ 0, c differs from A applied to the d’s. With n = 0, no constant denotes a pure entity.
- **□Axiom of Infinity (type e).** Necessarily, there are not finitely many individuals.
- **¬ Non-contingency of the Continuum Hypothesis.** Either necessarily every real number structure satisfies the continuum hypothesis, or necessarily every real number structure falsifies it: that every subproperty of the continuum either injects into the natural numbers or is in bijection with the continuum. One sentence for each type $\sigma$.
- **¬ □BF (type t).** Necessarily, if every proposition necessarily has a property, then necessarily every proposition has it.
- **¬ □Two-hat necessities are ND-necessary.** Necessarily, whatever is two-hat necessary is ND-necessary: the distinctness-preserving modality agrees with its hat. In C this is the identity $\hat{\hat\Box}=\Box_{\ne}$.
- **¬ Necessity of Analysis.** Every first-order analytical sentence is either true in every real number structure in every possible world or false in every real number structure in every possible world. One sentence for each type $\sigma$ and each first-order analytical sentence.
- **¬ Truths are ND-necessary.** Every truth is ND-necessary, that is, necessary under the distinctness-preserving modality.
- **¬ Vicinity.** There is a true proposition that entails the possibility of each true proposition.
- **¬ Weakly Inextensible Comprehension.** Every relation, including a proposition, is coextensive with a weakly inextensible one.
- **¬ Boolean Completeness (type t).** Every property of propositions has a greatest lower bound.
- **¬ Truths are 5-necessary.** Every truth is 5-necessary: necessary under every S5 operator.
- **¬ Countable Boolean Completeness.** Every countable property of entities of a relational type has a least upper bound in that type, where a property is countable relative to a type $\sigma$ when it injects into the finite cardinalities of properties of type $\sigma$; one instance for each $\sigma$.
- **¬ B for pure sentences.** The B instance for every closed sentence in the pure language.
- **¬ Witnessed Possibility.** For pure-formulas P with free variables among a finite tuple x, and distinct matching nonlogical constants c, a witness to P entails that P at those constants is possible.
- **¬ Separated Structure.** For each typed nonlogical constant c and closed same-typed terms F,G not containing c, equality after application to c implies equality of F and G.

## Definition

Assume in the metatheory that there is a transitive set model of ZFC, and let $L_\alpha$ be the least one: $\alpha$ is the least ordinal with $L_\alpha\models\mathrm{ZFC}$, which is countable. Let $N_+:=L_\alpha$, which satisfies CH, and $N_-:=L_\alpha[G]$ for a filter $G$ generic over $L_\alpha$ for the forcing adding $\aleph_2^{L_\alpha}$ Cohen reals, which exists because $L_\alpha$ is countable, so that $N_-\models\mathrm{ZFC}+\neg\mathrm{CH}$. Both are transitive with the same ordinals, so their natural numbers are the true ones. In each $N\in\{N_+,N_-\}$, carry out the construction of coalesced-pinned-substitutions-root with a single component, finite-support-monotone-maps as built in $N$, giving an action model $M_N$ with root object $R_N$. $N$ being transitive, $M_N$ is an action model of C in the metatheory, and a formula has the same truth value at a world of $M_N$ whether that is computed in $N$ or in the metatheory. The components are $M_{N_+}$ and $M_{N_-}$, and the root $W_0$ is built over them as in coalesced-pinned-substitutions-root. Evaluation point: $W_0$, at its identity arrow. Interpretation of Σ as there.

As for interpretation arrows, and the root has besides an arrow to itself for every type-preserving map of the signature's constants to themselves, acting on the root's individuals and composing with the interpretation arrows by precomposition.

As in coalesced-pinned-substitutions-root, intensions over the arrows out of $W_0$ pinned down by a finite set of constants of $\Sigma^+$, whose transports along the arrows into a component land in its domains.

### Fails Necessity of Analysis.

At type $et$, where there are real number structures at every reachable object (see the argument atomlessness-and-ch). Let $A$ be the first-order analytical sentence saying that some real codes a well-founded model of ZFC, a sentence of second-order arithmetic. At $W_0$, extensionally full at its identity, every real number structure at $et$ is isomorphic to the reals of the metatheory, and $A$ is true there: $L_\alpha$ is countable, so a real codes it. At $R_N$ and at $V_N$ every real number structure is isomorphic inside $N$ to $N$'s reals, and $A$ has there its truth value in $N$, since $N$ is transitive and well-foundedness of a relation on $\omega$ is absolute. In $N$, $A$ is false: a model coded by a real in $N$ that is well-founded collapses, inside $N$, to a transitive model $T$ of ZFC, of height $\beta<\alpha$ since $N$ has height $\alpha$; then $L^T=L_\beta\models\mathrm{ZFC}$, against the leastness of $\alpha$. So neither $\Box\forall\mathfrak R\,.\,\operatorname{Real}_{et}(\mathfrak R)\to A(\mathfrak R)$, false at the arrows into $R_{N_+}$, nor $\Box\forall\mathfrak R\,.\,\operatorname{Real}_{et}(\mathfrak R)\to\neg A(\mathfrak R)$, false at the identity, holds at $W_0$.

### Holds □Axiom of Infinity (type e).

In an action model a closed sentence holds at an arrow out of the evaluation object exactly when it holds at the identity arrow of the arrow's target, closed terms denoting entities that every arrow carries to the corresponding denotations at its target (in a one-world or Kripke-style model, the reachable objects are the worlds the evaluation point sees); so it suffices that the Axiom of Infinity at type $e$ holds at the identity arrow of every reachable object $v$. Fix such a $v$, and let $\Phi$ be the entity of type $(et)t$ in the domain at $v$ that holds there of exactly the properties with finite extension. The domain is closed under the operations defined by closed terms, so it contains $W:=\lambda Y^{(et)t}\, .\,\forall X^{et}\, .\,YX\to\Phi X$, which holds at $1_v$ of exactly the cardinalities holding there only of properties with finite extension. $W$ holds of $\mathbf 0_e$, which holds only of properties with empty extension. It passes from $Y$ to $\operatorname{Suc}_e Y$: if $\operatorname{Suc}_e Y$ holds of $X$, then $Xy$ and $Y(\lambda u\, .\,Xu\land u\ne y)$ for some $y$, and since identity at $e$ is literal at $1_v$ the extension of $\lambda u\, .\,Xu\land u\ne y$ is that of $X$ less $y$, which is finite as $W$ holds of $Y$; so $X$ has finite extension. Hence every $Z$ that is a finite cardinality at $1_v$ falls under $W$, and does not hold of $\lambda u\, .\,\top$, whose extension, all the individuals at $v$, is infinite. The step from the domain's entity $\Phi$ is what rules out a nonstandard finite cardinality: without it the impredicative ancestral ranges only over the domain's properties of cardinalities, which need not include one that excludes the universal property. No choice is used: "finite" means in bijection with a natural number, and an infinite set need not be Dedekind infinite.

On 30 October 2026, at the direction of Cian Dorr, the components were fixed as $L_\alpha$ and a Cohen extension of it, in place of arbitrary models of ZFC ± CH, so that arithmetic is standard everywhere and Arithmetic Necessitism holds; the model then shows that □Atomlessness with Arithmetic Necessitism gives neither the Non-contingency of CH nor the Necessity of Analysis. It assumes in the metatheory that ZFC has a transitive set model. Checked by Claude Opus 5.5 (Anthropic), prompted by Cian Dorr; it inherits the model-of-C argument of coalesced-pinned-substitutions-root, which has not had a second reader. No Lean verification is claimed.
