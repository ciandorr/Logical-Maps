# Functionality ⇒ Tractarianism

<p class='cert'>Result — Source: Classicism (2023 draft); produced by Andrew Bacon and Cian Dorr; recorded by OpenAI Codex (GPT-6), 17 September 2026.</p>

## Premises

- **Functionality.** Operations with the same value on every argument are identical. The output type is relational.

## Conclusion

- **Tractarianism.** A proposition entailing every instance of a property entails its universal generalization.

## Proof

Assume $p\le Fx$ for every x. Functionality identifies $F$ with $\lambda x\, .\,Fx\lor p$. Distribution of the constant disjunct through the universal quantifier identifies $\forall x\, .\,Fx$ with $(\forall x\, .\,Fx)\lor p$, which is the required entailment.
