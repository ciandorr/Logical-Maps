## Package

- **Relational Choice.** Every serial binary relation has a functional subrelation.
- **□Self-Atomicity.** Necessarily, at each relational type, every possible entity (one distinct from bottom) is entailed by a self-atom: a possible entity that necessarily, if instantiated, is an atom.
- **□Rigid Comprehension.** Necessarily, every relation, including a proposition, is coextensive with a rigid one.
- **□Intensional Choice.** Necessarily, if a property is necessarily instantiated, then some property entailing it is necessarily uniquely instantiated.
- **□BF.** Necessarily, the Barcan Formula holds at every type. The predicate formulation closes the formula schema using lambda abstraction.
- **Axiom of Infinity (type e).** There are not finitely many individuals. No finite cardinality holds of the universal property, so the domain of the type cannot be exhausted by finitely many steps from the empty property.
- **□Truths are ND-necessary.** Necessarily, every truth is ND-necessary. In C this is the identity $\Box_{\ne}=\lambda p\, .\,p$.
- **Mathematical Possibilism.** At each admitted carrier type, every complete Boolean algebra whose carrier contains no power-closed subcollection strictly larger than the inexact ordinal benchmark over individuals is relationally order-isomorphic to the propositions entailing some proposition.
- **¬ Non-contingency of the Continuum Hypothesis.** Either necessarily every real number structure satisfies the continuum hypothesis, or necessarily every real number structure falsifies it: that every subproperty of the continuum either injects into the natural numbers or is in bijection with the continuum. One sentence for each type $\sigma$.
- **¬ Self-atoms are atoms (type t).** Every self-atom is an atom.
- **¬ Atomicity (type t).** Every non-bottom proposition has an atom below it.
- **¬ ND (type t).** Distinct propositions are necessarily distinct.
- **¬ Rigid Rigidity.** Being rigid is a rigid property of relations, including propositions.
- **¬ Rigid Power.** If a relation is rigid, so is the property of being a rigid relation that entails it.
- **¬ □Axiom of Infinity (type t).** Necessarily, there are not finitely many propositions.
- **¬ □Potential Infinity (type t).** Necessarily, for every natural number there could be at least that many propositions.

## Definition

Work in ZFC. Fix a strong limit cardinal μ>ω with cf(μ)=ω. Use one representative of every nontrivial complete Boolean algebra of cardinality <μ (Definition 6.4). Take the disjoint union of the nonzero parts of these complete Boolean algebras, with refinement given by their Boolean orders, and adjoin a refinement-isolated root r. The root sees every point and each cloud point sees its refinements. Use the full modalized-domain model of Definitions 2.1–2.10 and 4.1, with constant individual domain ω and literal individual identity. At t use all regular-open propositions; at function types use the full underlying function sets with the partial equivalence relations of Definition 2.2. ### Holds Mathematical Possibilism. Conjectured.

The lottery represents all complete Boolean algebras of size below μ. To obtain the revised verdict it suffices to prove that the root inexact ordinal carrier has size below μ. Then any carrier of size at least μ contains a subset of size μ, strictly larger than H and power-closed by strong limit and full current extensions.
