# □Atoms are self-atoms (type t) ∧ □Intensional Choice ⇒ □Atoms are self-atoms

## Premises

- **□Atoms are self-atoms (type t).** Necessarily, every atom is a self-atom: necessarily, if it is true, it is an atom.
- **□Intensional Choice.** Necessarily, if a property is necessarily instantiated, then some property entailing it is necessarily uniquely instantiated.

## Conclusion

- **□Atoms are self-atoms.** Necessarily, at each relational type, every atom is a self-atom: necessarily, if it is instantiated, it is an atom.

The proof of [[atoms-are-self-atoms-t-and-intensional-choice-imply-atoms-are-self-atoms-r]] uses its premises only at finitely many closed instances and nothing beyond C. So for each closed instance of the conclusion, C proves the conditional from the corresponding premise instances to it. Necessitate that theorem and apply K with the boxed premise instances. Generalization over the admitted types is metalinguistic; no type quantifier is placed inside the box.
