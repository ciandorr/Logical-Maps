# □BF (type t) ∧ □Actuality ⇒ □Self-Atomicity (type t)

<p class='cert'>Result — Source: Misc.; produced by Cian Dorr, 28 October 2026; recorded by Claude Opus 5.5 (Anthropic), prompted by Cian Dorr, 28 October 2026.</p>

## Premises

- **□BF (type t).** Necessarily, if every proposition necessarily has a property, then necessarily every proposition has it.
- **□Actuality.** Necessarily, there is a true proposition that entails every true proposition.

## Conclusion

- **□Self-Atomicity (type t).** Necessarily, every possible proposition is entailed by a self-atom: a possible proposition that necessarily, if true, is an atom, that is, one that entails that it is the actual world.

## Proof

The proof of [[barcan-t-and-necessary-actuality-imply-self-atomicity-t]] derives Self-Atomicity (type $t$) in C from BF (type $t$) and □Actuality, so C proves $\Box(\mathrm{BF}_t\land\Box\mathrm{Act}\to\mathrm{SelfAt}_t)$ by necessitation. □Actuality gives $\Box\Box\mathrm{Act}$ by 4, and with $\Box\mathrm{BF}_t$, K gives $\Box\mathrm{SelfAt}_t$.

## Notes

Under □BF at every type, [[necessary-self-atomicity-t-and-necessary-bf-imply-necessary-self-atomicity-r]] lifts the conclusion to [[necessary-self-atomicity-r]], so □BF and □Actuality give □Self-Atomicity.
