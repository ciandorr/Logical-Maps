# □Strong Atomicity ⇒ □Atomicity

<p class='cert'>Result — Source: Philosophical Introduction to HOL (2024), Lean `Classicism.Map.necessary_strong_atomicity_implies_necessary_atomicity`; produced by Andrew Bacon; boxed form recorded by Claude Fable 5.1 (Anthropic), prompted by Cian Dorr, 22 September 2026; recorded by Claude Fable 5.1 (Anthropic), prompted by Cian Dorr, 22 September 2026.</p>

## Premises

- **□Strong Atomicity.** Necessarily, at each relational type, every possible entity (one distinct from bottom) is entailed by a strong atom: a possible entity that necessarily entails every entity of the type or its negation.

## Conclusion

- **□Atomicity.** Necessarily, every non-bottom entity of each relational type has an atom below it.

## Proof

Necessitate the recorded implication from Strong Atomicity to Atomicity, which is a theorem of C, and apply K.
