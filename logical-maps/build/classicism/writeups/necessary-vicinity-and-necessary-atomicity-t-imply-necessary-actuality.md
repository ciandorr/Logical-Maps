# □Vicinity ∧ □Atomicity (type t) ⇒ □Actuality

<p class='cert'>Result — Source: Misc.; produced by Cian Dorr (the argument and its use of BF for 5-necessity, 28 October 2026), with Claude Opus 5.5 (Anthropic), who completed the step showing that the atoms below the witness are self-atoms; recorded by Claude Opus 5.5 (Anthropic), prompted by Cian Dorr, 28 October 2026.</p>

## Premises

- **□Vicinity.** Necessarily, there is a true proposition that entails the possibility of each true proposition.
- **□Atomicity (type t).** Necessarily, every non-bottom proposition has an atom below it.

## Conclusion

- **□Actuality.** Necessarily, there is a true proposition that entails every true proposition.

## Proof

The proof of [[vicinity-and-atomicity-t-imply-actuality]] is a derivation in C, so C proves $\Box(\mathrm{Vic}\land\mathrm{Atom}_t\to\mathrm{Act})$ by necessitation, and K gives $\Box\mathrm{Act}$ from $\Box\mathrm{Vic}$ and $\Box\mathrm{Atom}_t$.
