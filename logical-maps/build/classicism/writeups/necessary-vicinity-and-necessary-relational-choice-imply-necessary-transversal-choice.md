# □Vicinity ∧ □Relational Choice ⇒ □Transversal Choice

<p class='cert'>Result — Source: Misc., Lean `Classicism.Map.necessary_vicinity_and_necessary_relational_choice_imply_necessary_transversal_choice`; produced by GPT-6 Astra (OpenAI), prompted by Daniel Kodsi, 26 October 2026 (the unboxed theorem); direct proof by Claude Opus 5.5 (Anthropic), prompted by Cian Dorr, 26–28 October 2026; recorded by Claude Opus 5.5 (Anthropic), prompted by Cian Dorr, 28 October 2026.</p>

## Premises

- **□Vicinity.** Necessarily, there is a true proposition that entails the possibility of each true proposition.
- **□Relational Choice.** Necessarily, every serial binary relation has a functional subrelation.

## Conclusion

- **□Transversal Choice.** Necessarily, every equivalence relation, at any type including e, has a transversal, that is, a property with exactly one instance in each of its cells.
