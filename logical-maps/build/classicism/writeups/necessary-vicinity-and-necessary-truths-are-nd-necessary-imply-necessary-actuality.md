# □Vicinity ∧ □Truths are ND-necessary ⇒ □Actuality

<p class='cert'>Result — Source: Misc., Lean `Classicism.Map.necessary_vicinity_and_necessary_truths_are_nd_necessary_imply_necessary_actuality`; produced by Cian Dorr, 27 September 2026 (unboxed form); boxed form recorded by Claude Opus 5.5 (Anthropic), 19 October 2026; recorded by Claude Opus 5.5 (Anthropic), prompted by Cian Dorr, 19 October 2026.</p>

## Premises

- **□Vicinity.** Necessarily, there is a true proposition that entails the possibility of each true proposition.
- **□Truths are ND-necessary.** Necessarily, every truth is ND-necessary. In C this is the identity $\Box_{\ne}=\lambda p\, .\,p$.

## Conclusion

- **□Actuality.** Necessarily, there is a true proposition that entails every true proposition.
