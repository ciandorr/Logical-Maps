# No Pure Contingency ∧ Self-Atomicity (type t) ⇒ □Self-Atomicity (type t)

<p class='cert'>Result — Source: Misc.; produced by Claude Fable 5.1 (Anthropic), prompted by Cian Dorr, 25 October 2026; recorded by Claude Fable 5.1 (Anthropic), prompted by Cian Dorr, 25 October 2026.</p>

## Premises

- **No Pure Contingency.** Each closed sentence of the pure language, if true, is necessary. This is a sentence schema, not a quantifier over propositions.
- **Self-Atomicity (type t).** Every possible proposition is entailed by a self-atom: a possible proposition that necessarily, if true, is an atom, that is, one that entails that it is the actual world.

## Conclusion

- **□Self-Atomicity (type t).** Necessarily, every possible proposition is entailed by a self-atom: a possible proposition that necessarily, if true, is an atom, that is, one that entails that it is the actual world.

## Proof

Every closed instance of Self-Atomicity (type t) is a closed sentence of the pure language, stated with object-language quantifiers and no nonlogical constant. Each is true, and No Pure Contingency makes each necessary, which is □Self-Atomicity (type t).
