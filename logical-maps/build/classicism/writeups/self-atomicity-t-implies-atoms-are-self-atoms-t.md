# Self-Atomicity (type t) ⇒ Atoms are self-atoms (type t)

<p class='cert'>Result — Source: Misc.; produced by Cian Dorr, 25 October 2026; recorded by Claude Fable 5.1 (Anthropic), prompted by Cian Dorr, 25 October 2026.</p>

## Premises

- **Self-Atomicity (type t).** Every possible proposition is entailed by a self-atom: a possible proposition that necessarily, if true, is an atom, that is, one that entails that it is the actual world.

## Conclusion

- **Atoms are self-atoms (type t).** Every atom is a self-atom: necessarily, if it is true, it is an atom.

## Proof

Let $p$ be an atom. It is possible, so Self-Atomicity (type t) gives a self-atom $q\le p$; as $q\ne\bot$ and $p$ is an atom, $q=p$, so $p$ is a self-atom.

## Notes

So Self-Atomicity lies between Atomicity with Atoms are self-atoms, which imply it, and Atoms are self-atoms alone; the converse fails, since Atoms are self-atoms holds vacuously wherever there are no atoms (symmetric-all-surjections) while Self-Atomicity fails there.
