## Package

- **□ND.** Necessarily, distinct things of any type are necessarily distinct.
- **Atomlessness.** Atomlessness in the displayed closed propositional formulation.
- **Boolean Completeness (type t).** Every property of propositions has a greatest lower bound.
- **Countable Boolean Completeness.** Every countable property of entities of a relational type has a least upper bound in that type, where a property is countable relative to a type $\sigma$ when it injects into the finite cardinalities of properties of type $\sigma$; one instance for each $\sigma$.
- **Axiom of Infinity (type e).** There are not finitely many individuals. No finite cardinality holds of the universal property, so the domain of the type cannot be exhausted by finitely many steps from the empty property.
- **BF.** The Barcan Formula at every type. The predicate formulation closes the formula schema using lambda abstraction.
- **Analytic Necessitism.** If there could be a real number structure, there is a rigid one that is necessarily a real number structure: a rigid property with necessarily distinct instances, with rigid order, addition, multiplication and natural numbers, which necessarily form a complete ordered field. One sentence for each type $\sigma$.
- **Arithmetic Necessitism.** Given that necessarily zero is not a successor and successor is injective on numbers, the numbers at $\sigma$ form a rigid property with necessarily distinct instances. One sentence for each type $\sigma$.
- **□Axiom of Infinity (type e).** Necessarily, there are not finitely many individuals.
- **No Pure Contingency.** Each closed sentence of the pure language, if true, is necessary. This is a sentence schema, not a quantifier over propositions.
- **Necessity of Second-Order Analysis.** Every second-order analytical sentence is either true in every real number structure in every possible world or false in every real number structure in every possible world. One sentence for each type $\sigma$ and each second-order analytical sentence.
- **Second-Order Analytic Necessitism.** If there could be a real number structure, there is a rigid one, necessarily a real number structure, together with represented powers of every arity up to $n$: rigid properties of rigid relations among the structure's elements that necessarily represent every relation on them. One sentence for each type $\sigma$ and each $n\ge1$.
- **No Contingency (signature Σ).** Each closed sentence of the language of the fixed signature Sigma, if true, is necessary. A sentence schema, standing to No Pure Contingency as Possibility Maximalism (signature Σ) stands to Possibility Maximalism (pure).
- **B for sentences of Σ.** The B instance for every closed sentence of the language of the fixed signature Sigma.
- **¬ Transversal.** There is a property of properties that picks out exactly one property from each coextension class, that is, exactly one property coextensive with any given property.
- **¬ Relational Choice.** Every serial binary relation has a functional subrelation.
- **¬ Intensional Choice.** If a property is necessarily instantiated, then some property entailing it is necessarily uniquely instantiated.
- **¬ Witnessed Possibility.** For pure-formulas P with free variables among a finite tuple x, and distinct matching nonlogical constants c, a witness to P entails that P at those constants is possible.
- **¬ Separated Structure.** For each typed nonlogical constant c and closed same-typed terms F,G not containing c, equality after application to c implies equality of F and G.
- **¬ Independence (signature Σ).** No constant of Sigma is a pure operation applied to other constants: for a closed pure term A and distinct constants c, d_1,…,d_n with n ≥ 0, c differs from A applied to the d’s. With n = 0, no constant denotes a pure entity.
- **¬ Maximalism (signature Σ).** The Maximalism schema for the fixed nonlogical signature Σ: every closed identity of its language not provable in C(Σ) is false.

## Definition

A symmetric ideally-full intensional action model over one object, the set of natural numbers, equipped with an equivalence relation that has infinitely many classes, each infinite. Its arrows are all the permutations of that set, and its symmetry group is the automorphism group of the equivalence relation: the permutations that map classes onto classes. The object carries the ideal of finite sets. The evaluation point is the identity arrow.

Individuals, fixed for this record: the individuals at each object are the base the construction describes, and the arrows act on them as on the base.

Interpretation of Σ, fixed for this record: every constant of Σ is relational, and each denotes the top element of its type.

*A member of the group Symmetric ideally-full models, which supplies this definition with the record's settings, and the arguments marked as shared.*

### Fails Transversal.

At type $e$. Write $G$ for the symmetry group and $\sim$ for the equivalence relation; the constant intension with value $\sim$ is symmetric and pinned down by $\varnothing$, so for an individual $a$ the property $\lambda x\, .\,x\sim a$, pinned down by $\{a\}$, has as extension the class of $a$. Suppose $F$, pinned down by a finite $S$, picked exactly one property from each coextension class, and let $Y$ be the one it picks with extension a class $C$ disjoint from $S$. A $g\in G$ fixing $S$ pointwise fixes $F$ (by pinning and symmetry), so $g\cdot Y$ is picked too; if $g$ also maps $C$ onto itself, $g\cdot Y$ has extension $g[C]=C$, so $g\cdot Y=Y$ by uniqueness, that is, $Y_{k\circ g}=Y_k$ for every arrow $k$. Let $Y$ be pinned down by a finite $T$. The permutations of each class fixing $S$ pointwise are such $g$; with the permutations fixing $T$ pointwise, which include transpositions across classes outside $T$, they generate every finitary permutation of $\mathbb N\setminus S$, and with the permutations fixing $T$ these generate all those fixing $S$ pointwise. So $Y$ is pinned down by $S$. Now take $g^{\prime}\in G$ fixing $S$ pointwise and exchanging $C$ with another class disjoint from $S$: $Y_{g^{\prime}}=Y_1$ by pinning, and $Y_{g^{\prime}}=g^{\prime}[Y_1]$ by symmetry, so $C=g^{\prime}[C]$, which is false. So there is no such $F$.

### Holds Atomlessness.

Let $p$ be a possible proposition, pinned down by a finite $N$ and containing the arrow $h$. Take distinct points $m,m^{\prime}\notin N$ and put $q:=\{k\in p : km\sim km^{\prime}\}$, symmetric and pinned down by $N\cup\{m,m^{\prime}\}$, so in the domain, with $q\le p$. A permutation agreeing with $h$ on $N$ and sending $m$ and $m^{\prime}$ to two fresh points of one class lies in $q$, and one sending them to fresh points of different classes lies in $p$ but not in $q$, both lying in $p$ by pinning. So $q$ is possible and $q\ne p$.

### Holds Boolean Completeness (type t).

Write $E_k:=\{(x,y) : kx\sim ky\}$ for an arrow $k$. If $E_k$ and $E_{k^{\prime}}$ agree on a finite $M$, the map $k(m)\mapsto k^{\prime}(m)$ preserves and reflects $\sim$, so it extends to an automorphism $g$ of the equivalence relation, the classes being infinitely many and infinite, and $g\circ k$ agrees with $k^{\prime}$ on $M$; so a proposition pinned down by $M$ contains $k$ iff it contains $k^{\prime}$. And for finite sets $A$ and $B$ and arrows $k_A$, $k_B$ with $E_{k_A}$ and $E_{k_B}$ agreeing on $A\cap B$, some permutation $k$ has $E_k$ equal to $E_{k_A}$ on $A$ and to $E_{k_B}$ on $B$: amalgamate the two equivalence relations over $A\cap B$ and send each class of the result into its own class. Now let $X$ be a property of propositions, pinned down by a finite $N$, and let $\ell$ hold at $h$ iff every arrow $k$ with $E_k=E_h$ on $N$ belongs to every member of $X$'s extension at the identity. $\ell$ is symmetric and pinned down by $N$, and it entails every member. Let $q$, pinned down by $M\supseteq N$, entail every member, and let $h\in q$; suppose some $k$ with $E_k=E_h$ on $N$ lies outside some member $p$, pinned down by $P$. Take a symmetry $g$ fixing $N$ pointwise that moves each point of $P\setminus N$ inside its class to a point outside $M$. Then $g\cdot p=\{k^{\prime} : k^{\prime}\circ g\in p\}$ is a member, $X$ being fixed by $g$, it is pinned down by $g(P)$, whose intersection with $M$ lies in $N$, and $k\circ g^{-1}$, which agrees with $k$ on $N$, lies outside it. An arrow $h^{\prime}$ with $E_{h^{\prime}}$ equal to $E_h$ on $M$ and to $E_{k\circ g^{-1}}$ on $g(P)$ lies in $q$ but not in $g\cdot p$, a contradiction. So $q\le\ell$, and $\ell$ is the greatest lower bound.

### Holds Countable Boolean Completeness.

At every relational type. First, an entity $Y$ pinned down by a finite $T$ and fixed by every symmetry fixing a finite $N$ pointwise is pinned down by $N$. For $Y$'s extension at $k\circ w$ equals its extension at $k$ both when $w$ is a symmetry fixing $N$ pointwise and, by pinning, when $w$ is any permutation fixing $T$ pointwise. These $w$ generate every permutation fixing $N$ pointwise: a transposition $(a\,b)$ of points outside $N$, with $a\in T$ say, is $(a\,c)(c\,b)(a\,c)$ for $c\notin T\cup N$ in the class of $a$, where $(a\,c)$ is a symmetry fixing $N$ and $(c\,b)$ fixes $T$ if $b\notin T$ (if $b\in T$, do the same for $b$); so every finitary permutation of the points outside $N$ is generated, and every permutation fixing $N$ pointwise agrees on $T$ with one of those. Now let $X$ be countable, and let a finite $N$ pin down both $X$ and an injection $I$ of $X$ into the finite cardinalities. These are standard and fixed by every arrow, as in the group's arguments for the Axiom of Infinity, so for a symmetry $g$ fixing $N$ pointwise and a member $Y$ of $X$'s extension, $g\cdot Y$ is a member too and $I$ assigns it the cardinality it assigns $Y$; so $g\cdot Y=Y$, and every member is pinned down by $N$. Their union, taken arrow by arrow, is then symmetric and pinned down by $N$, so in the domain, and it is the least upper bound, the order being inclusion of intensions.

### Holds □Axiom of Infinity (type e).

In an action model a closed sentence holds at an arrow out of the evaluation object exactly when it holds at the identity arrow of the arrow's target, closed terms denoting entities that every arrow carries to the corresponding denotations at its target (in a one-world or Kripke-style model, the reachable objects are the worlds the evaluation point sees); so it suffices that the Axiom of Infinity at type $e$ holds at the identity arrow of every reachable object $v$. Fix such a $v$, and let $\Phi$ be the entity of type $(et)t$ in the domain at $v$ that holds there of exactly the properties with finite extension. The domain is closed under the operations defined by closed terms, so it contains $W:=\lambda Y^{(et)t}\, .\,\forall X^{et}\, .\,YX\to\Phi X$, which holds at $1_v$ of exactly the cardinalities holding there only of properties with finite extension. $W$ holds of $\mathbf 0_e$, which holds only of properties with empty extension. It passes from $Y$ to $\operatorname{Suc}_e Y$: if $\operatorname{Suc}_e Y$ holds of $X$, then $Xy$ and $Y(\lambda u\, .\,Xu\land u\ne y)$ for some $y$, and since identity at $e$ is literal at $1_v$ the extension of $\lambda u\, .\,Xu\land u\ne y$ is that of $X$ less $y$, which is finite as $W$ holds of $Y$; so $X$ has finite extension. Hence every $Z$ that is a finite cardinality at $1_v$ falls under $W$, and does not hold of $\lambda u\, .\,\top$, whose extension, all the individuals at $v$, is infinite. The step from the domain's entity $\Phi$ is what rules out a nonstandard finite cardinality: without it the impredicative ancestral ranges only over the domain's properties of cardinalities, which need not include one that excludes the universal property. No choice is used: "finite" means in bijection with a natural number, and an infinite set need not be Dedekind infinite.

### Holds Necessity of Second-Order Analysis.

Let $v$ be reachable from the evaluation point. If every type is finite at $v$ there is no real number structure there, an ordered field having the infinitely many distinct elements $0$, $1$, $1+1$, and so on. Otherwise let $D$ be as in the condition. Carry the real numbers onto $D$ by a bijection: the carrier, order, sum, product, $0$, $1$ and natural numbers are sets of tuples from $D$, so extensions at $v$ of entities there, which form a real number structure $\mathfrak R^*$ at $v$, its completeness and the leastness of its natural numbers being tested against subproperties whose extensions are all the subsets of $D$. Its second-order quantifiers, applied to tuples from $D$, range over all relations on $D$, so for each second-order analytical sentence $A$, $A(\mathfrak R^*)$ holds at $v$ iff $A$ is true of the real numbers under full second-order semantics. Any real number structure $\mathfrak R$ at $v$, of any type, is isomorphic to $\mathfrak R^*$ by a relation in the domain there (Huntington's theorem, a theorem of C: Background, Analysis), and $A(\mathfrak R)\leftrightarrow A(\mathfrak R^*)$ is a theorem of C given such an isomorphism, relations on one carrier being carried to the other by comprehension. So at every reachable object every real number structure satisfies exactly the second-order analytical sentences true of the reals, and each instance $\Box\forall\mathfrak R\,.\,\operatorname{Real}_\sigma(\mathfrak R) \to A(\mathfrak R)$ or $\Box\forall\mathfrak R\,.\,\operatorname{Real}_\sigma(\mathfrak R)\to\neg A(\mathfrak R)$ of the Necessity of Second-Order Analysis holds, with the Necessity of Analysis and the Non-contingency of the Continuum Hypothesis. The choice of the bijection with the reals needs no choice principle, $D$ having the cardinality of the continuum.

## Notes

With all surjections as arrows this is symmetric-infinite-classes. Separates C5 from Transversal (and so from Transversal Choice and Actuality, which implies Transversal): a symmetric ideally-full model with invertible arrows, so C5 holds, in which the symmetry group, the automorphisms of an equivalence relation with infinitely many infinite classes, leaves no canonical representative of a class, as in symmetric-infinite-classes. Transversal holds in ideally full models with codomain intensions whatever the metatheory, the constant intension with value $E$ being a canonical member of each coextension class; it is the symmetry that removes those representatives. Intensional Choice fails too, at types $e$ and $t$, although no arrow collapses: an arrow carrying the pinning set into one class leaves every instance of $\lambda x\, .\,\neg(x\sim a)$ movable by the symmetries fixing its image (topic argument intensional-choice-moved-instances). Recorded with the base as individuals; the argument against Transversal does not apply to the generated variant with one individual.
