# Expected-utility representation ⇒ Completeness

<p class='cert'>Result — Source: Misc.; produced by Claude Fable 5.1 (Cowork session).</p>

## Premises

- **Expected-utility representation.** There is a function $u : X \to \mathbb{R}$ such that for all $p, q \in \Delta (X): p \succeq q$ if and only if $\operatorname{EU}_u(p) \ge \operatorname{EU}_u(q)$.

## Conclusion

- **Completeness.** For all $p, q \in \Delta (X): p \succeq q$ or $q \succeq p$.

## Proof

Real numbers are totally ordered: $\operatorname{EU}_u(p) \ge \operatorname{EU}_u(q)$ or $\operatorname{EU}_u(q) \ge \operatorname{EU}_u(p)$.
