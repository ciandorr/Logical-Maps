# Rational Affine Preservation ⇒ Integer Affine Preservation

<p class='cert'>Result — Source: Misc.; produced by Claude (Fable 5.1), 2026-09-24; recorded by Claude (Fable 5.1), 2026-09-24.</p>

## Premises

- **Rational Affine Preservation.** For every rational $a>0$ and real $b$: if $X \succeq Y$ then $aX+b \succeq aY+b$, and if $X \succ Y$ then $aX+b \succ aY+b$.

## Conclusion

- **Integer Affine Preservation.** For every positive integer $k$ and real $b$: if $X \succeq Y$ then $kX+b \succeq kY+b$, and if $X \succ Y$ then $kX+b \succ kY+b$.

## Proof

Restrict the rational factor $a>0$ to positive integers.

## Notes

Immediate restriction. Premises are sufficient; minimality is not claimed. No translation checker is asserted.
