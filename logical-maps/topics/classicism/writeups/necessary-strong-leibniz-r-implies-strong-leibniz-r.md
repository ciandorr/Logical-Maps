# Necessary Strong Leibniz implies Strong Leibniz

Fix an arbitrary admitted relational type $\tau$, and let $\varphi_\tau$
be the fully closed instance of the Strong Leibniz Biconditionals at that type.
The premise supplies $\Box\varphi_\tau$. The axiom T of C gives
$\Box\varphi_\tau\to\varphi_\tau$, so modus ponens yields
$\varphi_\tau$. Applying this argument separately at every relational type
gives the conclusion schema. No metalinguistic type quantifier moves inside
the box, and no necessitation of an optional premise is used.
