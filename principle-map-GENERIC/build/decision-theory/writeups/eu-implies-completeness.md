# Expected-utility representation ⇒ Completeness

<p class='cert'>Result — Source: Misc.; produced by Claude Fable 5.1 (Cowork session).</p>

## Premises

- **Expected-utility representation.** There is a function u : X → ℝ such that for all p, q ∈ Δ(X): p ≽ q if and only if EU_u(p) ≥ EU_u(q).

## Conclusion

- **Completeness.** For all p, q ∈ Δ(X): p ≽ q or q ≽ p.

## Proof

Real numbers are totally ordered: EU_u(p) ≥ EU_u(q) or EU_u(q) ≥ EU_u(p).
