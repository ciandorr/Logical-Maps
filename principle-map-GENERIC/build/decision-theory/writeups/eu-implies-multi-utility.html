Expected-utility representation ⇒ Expected multi-utility representation

Result — Source: Misc.; produced by Claude Fable 5.1 (Cowork session).

Premises

  • Expected-utility representation. There is a function u : X → ℝ such that for all p, q ∈ Δ(X): p ≽ q if and only if EU_u(p) ≥ EU_u(q).

Conclusion

  • Expected multi-utility representation. There is a set U of functions u : X → ℝ such that for all p, q ∈ Δ(X): p ≽ q if and only if EU_u(p) ≥ EU_u(q) for every u ∈ U.

Proof

Take U = {u}.
